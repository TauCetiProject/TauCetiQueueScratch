# TauCetiQueueScratch

The scratch repository of the Tau Ceti AI merge queue's cutover rehearsal
(`docs/queue/rehearsal.md` in TauCetiProject/TauCetiWorker). A minimal Lean library with no Mathlib
dependency, so `lake build` takes seconds, plus the `pr-build.yml` workflow the queue service drives
through `repository_dispatch`. Everything here is generated by `python -m tauceti_queue.rehearsal
scaffold`; synthetic pull requests come and go with every rehearsal run.
